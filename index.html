Care sunt posturile disponibile?

În prezent recrutăm montatori pentru instalații sanitare și termice în Germania și muncitori calificați pentru finisaje interioare în Köln.

Este obligatorie experiența?

Pentru finisaje interioare, experiența practică este obligatorie. Pentru instalații, experiența este un avantaj, iar pentru persoane serioase poate fi oferită instruire.

Pot aplica femeile pentru postul din Köln?

Da. Pentru finisaje pot aplica atât bărbați, cât și femei. Contează experiența, seriozitatea și calitatea lucrului.

Este asigurată cazarea?

Da. Cazarea este asigurată pentru ambele direcții. Pentru postul de finisaje din Köln este oferită gratuit.

Cum este organizat transportul?

Pentru instalații este achitat transportul până la destinația de lucru și este asigurată mașina de serviciu. Pentru finisaje este asigurat gratuit transportul la locul de muncă.

Se poate aplica cu pașaport moldovenesc?

Situația actelor și eligibilitatea pentru muncă sunt verificate individual înainte de plecare. Spune-ne ce documente ai, iar noi îți explicăm pașii aplicabili situației tale.

Trebuie să plătesc pentru aplicare?

Nu. Aplicarea și verificarea sunt gratuite. Nu cerem bani pentru rezervarea unui loc.
